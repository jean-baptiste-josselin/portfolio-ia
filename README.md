## Ce que présentera chaque projet

- **Besoin métier** : le problème étudié et les personnes concernées.
- **Solution** : l'approche retenue et les choix principaux.
- **Démonstration** : captures, exemple d'utilisation ou lien vers une démonstration.
- **Résultats** : observations et mesures effectivement obtenues.
- **Limites** : ce qui reste à améliorer et les conditions d'utilisation.
- **Code** : lien vers le dépôt du projet et instructions pour le lancer.

Les présentations seront regroupées dans un dossier `projets/`, créé avec la première fiche. Le code de chaque projet abouti disposera de son propre dépôt.
